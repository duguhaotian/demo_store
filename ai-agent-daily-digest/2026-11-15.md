## 1. Lauren Tan：把 Agent 当同事，一个月 1.1 万 PR、回滚 0.5%

**簇内独立帖 10** · X News 更新 2026-11-15 00:31 UTC

窗口内**最新、讨论最满**的工程博客。SpaceXAI / Grok Bot 工程师 Lauren Tan（@poteto）在 AI Engineer 的演讲 *All Code Is Slop (Except Mine)* 里说：小团队把 Agent 当成从头到尾写代码的同事，10 月合入约 1.1 万个 PR，回滚约 0.5%。做法不是「看每一行」，而是把每次纠错落成 lint / 架构约束，再叠运行时验证、TLA+ / Lean 形式化、属性测试；代码审查收缩成看验证产物（截图、录像、证明）。Agent 跑在独立云电脑上，有浏览器、文件和终端，能互相交任务。同一簇里 Sam Sokolin 还宣布 harness 优化大约多挤出 7% 套餐额度、常规任务最多约 15%。

## 3. Harrison Chase：Goal Engineering，按任务而不是按客户组 Agent

**簇内独立帖 10** · X News 更新 2026-11-14 23:59 UTC

融资博客的工程续篇，也是今日最像「方法论文」的一条。Chase 与 Actively AI 创始人 Mihir Garimella、Anshul Gupta 合写 *Goal Engineering: How to Design Goals*：Agent 缺的不是文档，是专家脑子里没写下来的偏好，所以**目标要按「人类最容易给反馈」来切**。Actively 第一版「一客户一 Agent」，销售在几十个审核队列间跳，外呼/推进成交的教训传不走；第二版改成建立在 Deep Agents 上的 **motion**（外呼、早期成交等同一类任务跨账户跑），一次纠错能改一整类。结尾句：prompt / context engineering 会消失，goal engineering 留下。
