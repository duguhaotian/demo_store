## 5. Ramp Labs × Baseten Speculative Encoding：一个 2.35B 翻译器在七个模型间传 KV，不用重新 prefill

## 7. Mark Ajzenstadt：能跑的 Agentic 系统有六层，失败几乎都在模型外面

**簇内独立帖 8** · X News 更新 2026-11-26 18:55 UTC

窗口内最清楚的生产架构长帖。Mark Ajzenstadt **11 月 26 日**写：公司把时间花在选模型上，而生产失败几乎都发生在模型外面的六层。（1）体验与触发：别默认聊天框，用文件到达、发票、工单、定时；人介入走异常队列。（2）编排与状态：Agent 定义要版本化、可回滚，执行历史进 Postgres，中断从 checkpoint 续。（3）工具与确定性逻辑：保证写在单测过的代码里，模型只做判断。（4）可信上下文：按域查询，不要把 wiki 倒进 prompt。（5）评测与人控：金标集、LLM-as-judge、高影响操作过审批。（6）运行时与控制面：所有调用走内网 LLM 网关，按租户虚拟钥匙、花费上限、注入护栏、全量 trace、内部模型别名。簇独立帖 8。和 #2 Thorsten 对着读：一家写人怎么用 Agent，一家写公司怎么把 Agent 当成操作系统来跑。

## 9. Anthropic：Claude Agent 把 Messages API 从 Python 迁到 Rust，单请求 CPU 降约 70%

**簇内独立帖 7** · X News 更新 2026-11-26 22:33 UTC

今日官方工程博客里最硬的一条。Anthropic **11 月 25 日**发 **Migrating our Messages API to Rust**（昨日检索未进榜，今日簇更新到 22:33）。2024 初到 2026 秋，Messages API 流量大约涨了 1800 倍。Claude 用一周写出核心请求路径的第一版 Rust；真正卡住的是 **验证**——Python 还在改、回复非确定性、不能读用户请求。他们把生产 API 本身做成 verifier：checkpoint + fingerprint 记录差异形状但不记录文本，协调 Agent 每 10–30 分钟按指纹分派工人 Agent。内环是沙箱里秒级对比 prompt；外环用影子流量看指纹是否消失；记忆环把工程师否决写进 CLAUDE.md。输入对齐从 4 月约 24% 升到 8 月 **99.6%**，9 月切公网流量，不停机、不冻功能。单请求 CPU 约 **-70%**，内存 **-80% 以上**，Claude Code 请求的中位 TTFT 约 **-20%**。5 月时 Claude 已写超过 80% 合入代码。簇独立帖 7，低于若干独立帖 10 的长帖，但是今天才在窗口里长起来的官方页。和昨日 Siren 对着看：一家问 Agent 会不会逃沙箱，一家已经让 Agent 在沙箱里改线上 API。
