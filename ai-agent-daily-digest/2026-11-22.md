## 1. Claude Code Code Mode：用一段 JavaScript 并行串起 Bash / Read / Edit

**簇内独立帖 8** · X News 更新 2026-11-22 00:26 UTC

窗口内最新、也最接近「产品原文」的编码 Agent 更新。Claude Code 2.1.323 起提供实验性 **Code Mode**：默认路径里 Claude 一轮只发出 Bash / Read / Edit 再读结果；打开后它改写一小段 JavaScript，在会话里一次跑完多步工具调用，本地过滤噪声，只把最后表达式送回模型。文档给的例子是：`$` 跑 shell、`file()` 读文件、`edit()` 精确替换，再把测试输出作为返回值。簇里 Anthropic 的 Addy Osmani 等人说复杂重构不必再一轮一轮等；早期测试者反馈输入/输出 token 大约少一半。开启方式是环境变量 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`，要求原生终端、Claude 订阅或 Console 账号，不支持 VS Code 面板、Desktop、云会话、Bedrock / Vertex 网关。和昨日 #3 手机遥控器、#5 swarm 骑手对着看：一家把 Agent 的手从「一次一个工具」换成「一次一段程序」。

## 3. Demirer / Musolff / Yang《Writing Code vs. Shipping Code》：异步编码 Agent 让 commit +240%，release 只 +30%

**簇内独立帖 9** · X News 更新 2026-11-21 22:34 UTC

窗口内讨论最满的编码 Agent 研究簇。MIT Sloan 的 Mert Demirer、沃顿的 Leon Musolff 和 Liyuan Yang 的 NBER w35275（2026 年 5 月，9 月修订）用 50 多万 GitHub 开发者加 AI 使用遥测做匹配事件研究：autocomplete 让 commit +30%，同步交互 Agent（Copilot / Claude / Codex 在 IDE 里看着干）累计 +180%，异步自主 Agent（GitHub Agent 一类丢进云端 VM）累计 **+240%**。效果沿生产链急剧衰减：项目数大约 +80%，真正的 release 只有 **+30%**；他们估计 AI 与人力的替代弹性约 0.23，更像强互补。四个软件市场里新应用数量明显增加，总使用量几乎不动。仓库「创建后第一个月再无活动」的比例从 2021 年的 60% 升到 2026 年的 69%。论文本身不是今天新写的，但是今天才在 X News 里聚成 9 帖的独立簇，专讲编码 Agent 而不是泛 AI 编程梗。和 #1 Code Mode、#7 swarm 对着读：速度已经不是瓶颈，发得出去、有人用才是。
