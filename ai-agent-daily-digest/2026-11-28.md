## 1. SandboxRouter / BoxRouter：给 Agent 沙箱一个 OpenRouter 式的统一路由

**簇内独立帖 8** · X News 更新 2026-11-27 23:04 UTC

窗口内最晚长起来的新原文产品页。Arthur Katcher 问为什么还没有沙箱界的 OpenRouter：Daytona、E2B、Vercel Sandbox 各有定价、限额和故障，Agent 却只能绑一家。开发者当天把 **SandboxRouter**（`npm i @sandboxrouter/sdk`）和 **BoxRouter** 推出来：一个 API 创建沙箱，按估计成本 / 速度 / 能力选供应商，启动失败就试下一家，记录写在 `sbx.attempts`。SandboxRouter 列出 36 家供应商（Agent37、Beam、Blaxel、Daytona、E2B、Vercel Sandbox、Cloudflare 等），MIT 开源，也可以用一把托管钥匙。11 月 17 日他们用自己的账号在 12 家供应商里打 1,000 个并发：11 家接满 1,000/1,000，64 秒结束；跑起来的沙箱不搬家。短 CPU 任务里 Boat 估计最便宜（约 $0.015 / 1,000 次），Modal 启动后最快（427 ms）。簇独立帖 8，更新到 23:04。和昨日 Van Horn / Psychoscript 对着读：一家选 Agent 握着的鼠标，一家让 Agent 写的脚本能暂停，一家给脚本跑的那只盒子做故障转移。
