## 5. Anthropic：把子 Agent 折回单循环，技能按需展开

**簇内独立帖 7** · X News 更新 2026-11-17 23:32 UTC

官方工程博客，对着过去一年「编排器 + 分类器 + 专家子 Agent」的企业架构喊停。Anthropic 建议默认回到 **一个模型、一个上下文窗口、开放式工具循环**：每轮批量调工具，harness 并行执行，原始结果回到同一窗口；子 Agent 的知识写成 skill，API 变成主循环直接调用的工具，描述先短后展开。企业对比里，带 skill 的单 Agent 常常比「一个提示包打天下」和「子 Agent 森林」质量更好、更便宜、延迟更低。子 Agent 仍留给上下文膨胀、必须并行丢弃窗口、或工具选择冲突这几类情况。配套放出参考实现 `single-agent-loop-kit`。和 #3 OpenCrawl、#10 Devin Bots 是同一天的三种编队哲学。
