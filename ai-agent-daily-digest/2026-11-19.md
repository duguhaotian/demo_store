## 3. Architect Labs Frostbite：Agent 集群从零共设 ISA 并做到最终 GDS

## 9. Google SIM：给 harness 优化器一本「为什么改过」的记忆

**簇内独立帖 7** · X News 更新 2026-11-18 20:30 UTC

Google Cloud AI、DeepMind 合作者与宾州州立的预印本。 **Self-Improvement Memory (SIM)** 不是给干活的策略模型记笔记，而是给 **harness 优化器** 记：这次改提示/工具/检查是为了哪个根因、预期修哪些题、实测如何。换基准或换模型时，优化器带着这本账继续，而不是只留下演化后的 harness。编码域十次独立源跑上，配对续跑平均比「只带 harness」高 **2.36 分**。同日 Abundant 的 **FrontierRSI** 把「Agent 能不能做让自己变好的研究」做成 27 道开放题，Claude Opus 5.5 早期 34.3% 领先。簇里常把两件事绑在一起讲：记忆让改进可迁移，基准测改进是否真发生。

## 10. Bespoke Labs MAC Bench：八个 Agent 赢在人多，不赢在会商量

**簇内独立帖 7** · X News 更新 2026-11-18 20:14 UTC

窗口内最完整的多 Agent 协调原文。Bespoke Labs 的 **MAC Bench**（Multi Agent Coordination Bench）用 12 个天生需要协作的任务——迪拜空管、火星采样返回、电网恢复、僵尸生存——测 Opus 5.5、GPT-6.1 Sol、Gemini 4 Argon。墙钟一律四小时。八个 Agent 平均 0.42，单 Agent 0.35；**关掉留言板的八人队反而是 0.44**。协调贡献 −0.018，置信区间穿过零。只有 Opus 从传话里获益；Sol 广播不听；Gemini 16 次八人跑里有 9 次没有稳定分工。重复劳动出现在 64% 的团队跑。八人队成本约 8.8 倍，单位美元得分仍是单 Agent 最高。和昨日 Anthropic「折回单循环」对得上：人多不等于会协作。

- 基准目录：[Bespoke Labs Benchmarks](https://benchmarks.bespokelabs.ai/)
